Getting Started

Create and deploy as many web apps as you like.

The Aerobatic add-on can be installed at the team level or the individual user level.

Step 1: Install Aerobatic Add-On

  1. Log in to Bitbucket
  2. Click avatar > Manage account
  3. Click Find new add-ons
  4. For the Aerobatic add-on, click Install

Step 2: Create & Deploy App

  • Existing Repo
  • New Repo

  1. Go to your repository in Bitbucket
  2. Click Aerobatic Hosting
  3. Click Link this repo to Aerobatic
  4. Push code to repository

  1. From your team page, click Aerobatic
  2. Click Create App
  3. Select app template from gallery
  4. Click Link this repo to Aerobatic
  5. Push code to repository

Your app is now live at appname.aerobatic.io
