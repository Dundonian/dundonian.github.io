# Aerobatic for Bitbucket

This will be the destination for bitbucket.aerobatic.com  - The main marketing and docs site for our bitbucket users. It's a jekyll app based on the "agency" theme

# How to use

###Portfolio 

Portfolio projects are in '/_posts'

Images are in '/img/portfolio'

###About

Images are in '/img/about/'

###Team

Team members and info are in '_config.yml'

Images are in '/img/team/'
